# M.Store - نظام إدارة مخازن وحسابات مصانع  👜

نظام متكامل تم تطويره باستخدام **ASP.NET** و **SQL Server** لإدارة العمليات اليومية لمصنع . يوفر النظام حلولاً دقيقة لمتابعة المخزون، المبيعات، والتحصيلات.

## ✨ المميزات الرئيسية:
- **ملخص أداء لحظي:** لوحة تحكم تعرض إجمالي المبيعات، ديون العملاء، وديون الموردين.
- **إدارة الديون:** نظام متطور لمتابعة مديونيات العملاء وتاريخ الفواتير.
- **التقارير:** تقارير تفصيلية عن أصناف المخزن وإجمالي الهالك.
- **سهولة التحصيل:** واجهة بسيطة لتسجيل مبالغ التحصيل وتحديث الأرصدة فوراً.
